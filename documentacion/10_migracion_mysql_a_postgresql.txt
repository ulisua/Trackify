ESTADO (17/11/2026): TRACKIFY USA SOLO POSTGRESQL.
El grupo decidió usar PostgreSQL. Se quitó el soporte de MySQL del
código y trackify.sql (el esquema MySQL) se eliminó.

Cómo se llegó hasta acá:
  10/11/2026  El código pasa de mysqli a PDO (includes/db.php) y
              funciona con los dos motores, elegidos con DB_DRIVER.
  17/11/2026  Se quita MySQL: el código queda solo para PostgreSQL y
              se agrega la herramienta que copia los datos de MySQL.


---------------------------------------------------------------------
1. QUÉ CAMBIÓ EN EL CÓDIGO
---------------------------------------------------------------------
  includes/db.php           Clase BaseDatos solo con PostgreSQL (DSN
                            pgsql, RETURNING en insertar()). Se quitaron
                            $motor, esPostgres() y sqlMes().
  conexion.php              Lee DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASS
                            o DATABASE_URL, y DB_SSLMODE. Ya no existe
                            DB_DRIVER. Si falta la extensión pdo_pgsql
                            lo dice en pantalla.
  includes/migraciones.php  Solo sentencias de PostgreSQL (información
                            de information_schema y pg_indexes).
  index.php, ia.php         Agrupan por mes con TO_CHAR(fecha, 'YYYY-MM').
  registro.php, auth/google Columna foto_perfil en minúscula.
  trackify_postgres.sql     Único esquema (tablas, índices, FK y las 27
                            categorías predeterminadas).
  trackify.sql              Eliminado.
  herramientas/migrar_mysql_a_postgres.php
                            Nuevo: copia los datos de MySQL a PostgreSQL.
  .env.example              Variables de PostgreSQL (sin DB_DRIVER).

Las páginas no cambiaron: todas consultan a través de $conn
(BaseDatos), que ya se usaba desde el pasaje a PDO.


---------------------------------------------------------------------
2. PASOS PARA CADA INTEGRANTE (una sola vez)
---------------------------------------------------------------------
1) Instalar PostgreSQL 16 desde postgresql.org/download (Windows).
   Trae pgAdmin y psql. Anotar la contraseña del usuario "postgres" y
   dejar el puerto 5432.

2) Habilitar el driver en PHP: en C:\xampp\php\php.ini quitar el ";"
   de la línea
     ;extension=pdo_pgsql
   Guardar y reiniciar Apache desde el panel de XAMPP.

3) Crear la base e importar el esquema (en una consola dentro de la
   carpeta del proyecto; psql está en C:\Program Files\PostgreSQL\16\bin):
     createdb -U postgres trackify
     psql -U postgres -d trackify -f trackify_postgres.sql
   O con pgAdmin: Databases > Create > Database "trackify"; después,
   sobre la base, Query Tool > abrir trackify_postgres.sql > Ejecutar.

4) En .env (copiar los nombres de .env.example):
     DB_HOST=localhost
     DB_PORT=5432
     DB_NAME=trackify
     DB_USER=postgres
     DB_PASS=la_contraseña_del_paso_1
   Borrar DB_DRIVER si estaba (ya no se usa).

5) (Opcional) Traer los datos de la base MySQL vieja. Con MySQL de
   XAMPP encendido:
     C:\xampp\php\php.exe herramientas/migrar_mysql_a_postgres.php
   - Copia usuarios, categorías (del sistema y propias), metas,
     movimientos y consejos con sus mismos ids, y ajusta los
     contadores (secuencias) para que los próximos ids no choquen.
   - Sirve para cualquier versión vieja de la base (Icono_tipo,
     Foto_perfil, sin @usuario...): al final aplica las migraciones.
   - Todo va en una transacción: si algo falla no queda nada a medias.
   - Si la base MySQL no es localhost/root/sin clave/"trackify":
       ... migrar_mysql_a_postgres.php --usuario=root --clave=xxx --base=otra
   - Si PostgreSQL ya tiene usuarios, se niega a pisarlos; para
     reemplazarlos por los de MySQL agregar --forzar.
   Después de esto MySQL ya no hace falta.

6) Abrir http://localhost/trackify y probar (ver sección 4).

3. BASE EN LA NUBE (para publicar la app)
---------------------------------------------------------------------
Render, Neon y Supabase dan una URL de conexión. En .env (o en las
Environment Variables del servicio):
  DATABASE_URL=postgresql://usuario:clave@host:5432/base
  DB_SSLMODE=require
Si DATABASE_URL está definida, tiene prioridad sobre los DB_*. El
esquema se importa igual (psql con esa URL, o la consola SQL del
servicio con el contenido de trackify_postgres.sql).

5. REGLAS DE SQL EN POSTGRESQL (para código nuevo)
---------------------------------------------------------------------
- Siempre con $conn y parámetros "?", nunca valores concatenados.
- Nombres de tablas y columnas en minúscula y sin comillas.
- "=" distingue mayúsculas: emails con LOWER(email) = ? (el email se
  guarda en minúscula). Para buscar texto sin distinguir: ILIKE.
- GROUP BY estricto: toda columna del SELECT que no esté en una
  función de agregado (SUM, COUNT...) va en el GROUP BY.
- Agrupar por mes: TO_CHAR(fecha, 'YYYY-MM'). Fechas relativas
  ("hace 2 meses"): calcularlas en PHP con inicioDeMes() y pasarlas
  como parámetro.
- Ordenar por una condición: ORDER BY CASE WHEN ... THEN 0 ELSE 1 END
  (con "ORDER BY col = ? DESC" los NULL quedan primero).
- Id del registro insertado: $conn->insertar($sql, $params, 'id_columna')
  (agrega RETURNING).
- email_verificado y es_hormiga son SMALLINT 0/1 (no BOOLEAN): se
  comparan con 0/1.
- PDO devuelve NUMERIC como texto ("1500.00"): convertir con (float)
  antes de hacer cuentas en PHP.
- Columna nueva: agregarla en includes/migraciones.php
  (COLUMNAS_ESPERADAS + SQL_COLUMNAS_NUEVAS) y en trackify_postgres.sql.

6. EQUIVALENCIAS DE TIPOS (MySQL -> PostgreSQL), como referencia
---------------------------------------------------------------------
  MySQL                          PostgreSQL (en trackify_postgres.sql)
  -----------------------------  ------------------------------------
  INT AUTO_INCREMENT             SERIAL
  TINYINT(1)                     SMALLINT (0/1)
  ENUM('ingreso','gasto')        CREATE TYPE tipo_movimiento AS ENUM
  ENUM('activo',...)             CREATE TYPE estado_meta AS ENUM
  ENUM('ARS','USD')              VARCHAR(3) + CHECK
  DECIMAL(12,2)                  NUMERIC(12,2)
  DATETIME                       TIMESTAMP
  TIMESTAMP ... ON UPDATE        TIMESTAMP + trigger (consejos_ia)
  `nombre` (backticks)           sin comillas, en minúscula
  ENGINE=InnoDB, CHARSET=...     no existen (la base se crea en UTF-8)
  KEY x (col)                    CREATE INDEX x ON tabla (col)

7. PROBLEMAS FRECUENTES
---------------------------------------------------------------------
"Falta la extensión pdo_pgsql de PHP"
   -> Paso 2: quitar el ";" de extension=pdo_pgsql y reiniciar Apache.
"No se pudo conectar con PostgreSQL"
   -> El servicio "postgresql-x64-16" no está iniciado (Servicios de
      Windows) o DB_* de .env no coincide (sobre todo DB_PASS).
"relation ... does not exist"
   -> No se importó trackify_postgres.sql en la base de DB_NAME.
El script de migración dice "No se pudo conectar a MySQL"
   -> Encender MySQL en XAMPP o pasar --usuario/--clave/--base.
